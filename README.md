# React Currency Converter (freeCodeCamp Lab)

โปรเจคตัวแปลงสกุลเงิน (Currency Converter) สร้างขึ้นเพื่อผ่านโจทย์ข้อกำหนดในหลักสูตร [Front-End Development Libraries Certification](https://www.freecodecamp.org/learn/front-end-development-libraries-v9) ของ [freeCodeCamp](https://www.freecodecamp.org/learn)

## Tech Stack
- React (JSX)
- CSS3 (Custom Styling)

## User Stories / Features
- รองรับการกรอกตัวเลขจำนวนเงินที่ต้องการแปลง
- มีตัวเลือกสกุลเงินหลักอย่างน้อย USD, EUR, GBP และ JPY
- ใช้งานระบบ memoize เพื่อคำนวณประสิทธิภาพการเปลี่ยนสกุลเงิน
- แสดงผลลัพธ์พร้อมทศนิยม 2 ตำแหน่งและรหัสสกุลเงิน (XX.XX CCC)
